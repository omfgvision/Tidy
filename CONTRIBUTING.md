# Tidy project notes

Keep changes focused and avoid unnecessary redesigns.

Branding rules:
- Product name: Tidy
- HTML title: Tidy
- Light mascot: Tidy / broom
- Dark mascot: Moppy / mop

Do not replace intentional product copy with generic AI-generated marketing wording.

Before merging a change, test the core flow:
upload -> choose an operation -> process -> preview -> download

Do not claim a media format is supported unless the browser-side implementation can genuinely process it.
